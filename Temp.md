# How to Add Frickbear's 3 Mods With a Data.win File

<a href="https://gamebanana.com/tuts/19605"><img src="https://gamebanana.com/tuts/embeddables/19605?type=large"/></a>

Hello! This is a tutorial for Frickbear's 3 that shows you how to install a mod that comes with a data.win file.

Have you ever downloaded a mod that includes a "Data.win" and had no idea what to do with it?  
Follow the steps below (use the images as references) or watch the video!

---

### Step 1 - Go to your Frickbear's 3 folder

Open the folder where Five Nights At Frickbear's 3 is installed.

### Step 2 - Create a backup folder

Create a new folder and name it whatever you want (as long as you’ll remember it’s your backup).

Copy the `data.win` file that’s already inside the Frickbear's 3 folder.

### Step 6 - Paste the mod’s data.win into the game folder

Paste the mod’s `data.win` into the main Frickbear's 3 folder (the one that originally had the data.win).

---

### Congratulations!

You’re done! The changes from the mod should now show up in-game.

---

### Errors?

Only look at this part if something went wrong.

- Make sure you backed up the original data.win first.  
- If the game doesn’t start or looks broken, just put the original data.win back from your backup folder and try again.  
- Double-check that you replaced the correct data.win.
