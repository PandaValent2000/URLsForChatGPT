Hello! This is a tutorial for Frickbears 3 which tells you how to install a data.win/delta patch mod OF Frickbears 3!

Step 1 - Download Delta Patcher

Go and download Delta Patcher from github. (don't install the source code)

Step 2 - Open Delta Patcher

After installing Delta Patcher, unzip the folder and run DeltaPatcher.exe (might have a different name)

Step 3 - Patch the mod

In Delta Patchers interface, you'll see 2 boxes, Original File and XDelta Patch.



First, click the folder icon to the right of Original File. This brings up a new window where you must find your Frickbear's data.win, and select it. (Press "Open" on the data.win)


Now, press the folder icon to the right of XDelta Patch, and choose the XDelta file of whatever mod you downloaded.



Once you do both those things, simply press the "Apply Patch" button on the bottom of your Delta Patcher, and once it finishes patching, you should be good to go!


Step 4 - ERRORS?

Only look at this step if the patching failed for whatever reason.

If your patching failed, its most likely because your not on the right version of Frickbears OR you already have a mod installed. Simply install a fresh version of Frickbears and try again.

If it's neither of those, maybe the mod that you're trying to install is out of date? Ask the mod maker what version of Frickbears it's for if it isn't already said on the modpage.
